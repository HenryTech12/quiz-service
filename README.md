# Quiz Service - Microservices Project

This is the Quiz Service in a microservices-based Java architecture. It manages quizzes and communicates with the Question Service using Feign Client to fetch associated questions. The service is registered with Eureka for service discovery.

## Technologies Used

- Java 17+
- Spring Boot
- Spring Web
- Spring Cloud OpenFeign
- Spring Data JPA
- Eureka Client
- Maven

## Features

- CRUD operations on quizzes
- Fetch questions from Question Service via Feign Client
- Service discovery through Eureka
